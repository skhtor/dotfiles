### Usage

Run the following command to do a full install on a new Mac:
```
# Clone this repo
git clone https://github.com/skhtor/dotfiles ~/dotfiles

# Run setup
cd ~/dotfiles && ./setup_mac.sh
```

Before running, uncomment the relevant section in `Brewfile` (Personal or Work) for your machine.
